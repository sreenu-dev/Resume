# What Coding Questions You Can Expect from Chubb

## Common Problem Categories

### 1. Array and String Problems
**Difficulty**: Easy to Medium
**Examples**:
- Two Sum
- Reverse String
- Remove Duplicates from Sorted Array
- Best Time to Buy and Sell Stock
- Rotate Array
- Merge Sorted Array
- Container With Most Water
- Trapping Rain Water

**Key Concepts**:
- Sliding window
- Two pointers
- Prefix sums
- Hash maps

### 2. Linked List Problems
**Difficulty**: Easy to Medium
**Examples**:
- Reverse Linked List
- Merge Two Sorted Lists
- Remove Nth Node From End
- Detect Cycle in Linked List
- Palindrome Linked List
- Flatten Multilevel Doubly Linked List

**Key Concepts**:
- Pointer manipulation
- Fast and slow pointers
- Recursion

### 3. Tree and Graph Problems
**Difficulty**: Medium to Hard
**Examples**:
- Binary Tree Traversal (Inorder, Preorder, Postorder)
- Level Order Traversal
- Lowest Common Ancestor
- Path Sum
- Serialize and Deserialize Binary Tree
- Number of Islands
- Course Schedule (Topological Sort)
- Word Ladder

**Key Concepts**:
- DFS and BFS
- Tree traversal
- Graph algorithms
- Topological sorting

### 4. Hash Table and Set Problems
**Difficulty**: Easy to Medium
**Examples**:
- Valid Anagram
- Group Anagrams
- Intersection of Two Arrays
- Happy Number
- Isomorphic Strings
- Word Pattern

**Key Concepts**:
- Hash maps
- Sets
- Frequency counting

### 5. Stack and Queue Problems
**Difficulty**: Easy to Medium
**Examples**:
- Valid Parentheses
- Min Stack
- Evaluate Reverse Polish Notation
- Daily Temperatures
- Sliding Window Maximum
- Implement Queue using Stacks

**Key Concepts**:
- Stack operations
- Queue operations
- Monotonic stack

### 6. Dynamic Programming
**Difficulty**: Medium to Hard
**Examples**:
- Climbing Stairs
- House Robber
- Coin Change
- Longest Increasing Subsequence
- Edit Distance
- Longest Common Subsequence
- Partition Equal Subset Sum

**Key Concepts**:
- Memoization
- Tabulation
- State definition
- Recurrence relations

### 7. Sorting and Searching
**Difficulty**: Easy to Medium
**Examples**:
- Binary Search
- Search in Rotated Sorted Array
- Find First and Last Position of Element
- Merge K Sorted Lists
- Kth Largest Element

**Key Concepts**:
- Binary search variations
- Merge sort
- Quick sort
- Heap operations

### 8. Greedy Problems
**Difficulty**: Medium
**Examples**:
- Jump Game
- Gas Station
- Interval Scheduling
- Reconstruct Itinerary

**Key Concepts**:
- Greedy choice property
- Optimization

## Difficulty Distribution

### Easy Problems (20-30%)
- Basic array/string manipulation
- Simple tree traversal
- Hash table lookups
- Stack/queue operations

### Medium Problems (50-60%)
- Combined data structures
- Moderate algorithms
- Some optimization required
- Real-world scenarios

### Hard Problems (10-20%)
- Complex algorithms
- Multiple data structures
- Significant optimization
- Edge case handling

## Problem-Solving Approach

### Step 1: Understand the Problem
- Read the problem carefully
- Identify inputs and outputs
- Ask clarifying questions
- Work through examples

### Step 2: Plan Your Solution
- Discuss approach with interviewer
- Identify data structures needed
- Think about time and space complexity
- Consider edge cases

### Step 3: Implement
- Write clean, readable code
- Use meaningful variable names
- Add comments if needed
- Handle edge cases

### Step 4: Test
- Test with provided examples
- Test with edge cases
- Verify time and space complexity
- Optimize if needed

## Time Complexity Expectations

### Acceptable Complexities by Problem Type
| Problem Type | Acceptable Time | Avoid |
|---|---|---|
| Array/String | O(n), O(n log n) | O(n²) |
| Tree/Graph | O(n), O(n log n) | O(2^n) |
| DP | O(n²), O(n³) | O(2^n) |
| Sorting | O(n log n) | O(n²) |

## Tips for Coding Interviews

1. **Communicate**: Explain your thinking as you code
2. **Optimize**: Start with brute force, then optimize
3. **Code Quality**: Write clean, readable code
4. **Edge Cases**: Always consider edge cases
5. **Testing**: Test your solution thoroughly
6. **Complexity Analysis**: Be able to explain time and space complexity
7. **Variations**: Be ready for follow-up questions

## Practice Recommendations

### LeetCode Patterns
- Focus on "Blind 75" or "Grind 169" lists
- Practice problems by category
- Solve 2-3 problems daily
- Review solutions and learn patterns

### Mock Interviews
- Use platforms like Pramp or Interviewing.io
- Practice with peers
- Record and review your performance
- Get feedback on communication

### Study Groups
- Join coding interview groups
- Discuss approaches with others
- Learn different perspectives
- Stay motivated

## Framework-Specific Considerations

### For .NET Developers
- Be familiar with LINQ operations
- Understand async/await patterns
- Know about collections (List, Dictionary, HashSet)
- Understand delegates and lambda expressions

### For Angular Developers
- Understand JavaScript/TypeScript fundamentals
- Know about closures and prototypes
- Understand async operations (Promises, Observables)
- Be familiar with array methods (map, filter, reduce)

### For Objective-C Developers
- Understand memory management
- Know about NSArray, NSDictionary operations
- Understand blocks and closures
- Be familiar with Objective-C runtime concepts
