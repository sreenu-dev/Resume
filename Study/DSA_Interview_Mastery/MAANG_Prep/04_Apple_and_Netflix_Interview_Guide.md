# Apple and Netflix Interview Guide

## Apple Interview Guide

### Company Overview
- **Focus**: Hardware-software integration, user experience
- **Interview Style**: Practical, system design, product thinking
- **Difficulty**: Medium to Hard
- **Time Limit**: 45 minutes per problem

### Apple Interview Process
1. **Phone Screen** (1 round): 1 medium problem
2. **On-Site** (4-5 rounds):
   - 2-3 Coding rounds
   - 1 System Design round
   - 1 Behavioral round

### Apple-Specific Problems
1. **Two Sum** - Hash map
2. **Reverse Linked List** - Pointer manipulation
3. **Longest Substring Without Repeating** - Sliding window
4. **Median of Two Sorted Arrays** - Binary search
5. **Merge K Sorted Lists** - Min heap
6. **Number of Islands** - DFS/BFS
7. **LRU Cache** - Hash map + doubly linked list
8. **Coin Change** - DP
9. **Word Ladder** - BFS
10. **Trapping Rain Water** - DP/Two pointer
11. **Serialize/Deserialize Tree** - Tree traversal
12. **Lowest Common Ancestor** - Tree DFS
13. **Merge Intervals** - Sorting
14. **Search in Rotated Sorted Array** - Binary search
15. **Container With Most Water** - Two pointer
16. **3Sum** - Sorting + two pointer
17. **Longest Palindromic Substring** - DP
18. **Permutations** - Backtracking
19. **Word Search** - Backtracking
20. **Decode Ways** - DP

### Apple Interview Tips
- **Product Thinking**: Understand user perspective
- **Optimization**: Focus on efficiency
- **Quality**: Code quality matters
- **Communication**: Clear explanation
- **Edge Cases**: Handle all scenarios

### Apple-Specific Topics
1. **iOS/macOS Integration**
   - Platform-specific optimization
   - User experience focus

2. **Hardware Constraints**
   - Memory optimization
   - Battery efficiency

3. **Real-time Systems**
   - Low latency requirements
   - Responsiveness

### Behavioral Focus
- Innovation and creativity
- Attention to detail
- User-centric thinking
- Quality obsession
- Collaboration

## Netflix Interview Guide

### Company Overview
- **Focus**: Streaming, recommendations, scalability
- **Interview Style**: Algorithm-heavy, system design
- **Difficulty**: Hard
- **Time Limit**: 45 minutes per problem

### Netflix Interview Process
1. **Phone Screen** (1 round): 1 medium-hard problem
2. **On-Site** (4-5 rounds):
   - 2-3 Coding rounds
   - 1-2 System Design rounds
   - 1 Behavioral round

### Netflix-Specific Problems
1. **Median of Two Sorted Arrays** - Binary search
2. **Merge K Sorted Lists** - Min heap
3. **LRU Cache** - Hash map + doubly linked list
4. **Number of Islands** - DFS/BFS
5. **Longest Substring Without Repeating** - Sliding window
6. **Coin Change** - DP
7. **Word Ladder** - BFS

### Netflix Interview Tips

|--------|-------|---------|

## Preparation Strategy for Both

### Week 1-2: Foundation
- Master data structures
- Practice basic algorithms
- Understand complexity analysis

### Week 3-4: Medium Problems
- Solve 30-40 medium problems
- Focus on company-specific problems
- Practice explaining solutions

### Week 5-6: Hard Problems
- Solve 15-20 hard problems
- Practice under time pressure
- System design basics

### Week 7-8: Final Polish
- Mock interviews
- Weak area review
- Behavioral preparation
- System design practice
