# Meta (Facebook) Interview Guide

## Company Overview
- **Focus**: Large-scale systems, real-time products
- **Interview Style**: Practical, system design emphasis
- **Difficulty**: Medium to Hard
- **Time Limit**: 45 minutes per problem

## Interview Process
1. **Phone Screen** (1 round): 1 medium problem
2. **On-Site** (4-5 rounds):
   - 2-3 Coding rounds
   - 1-2 System Design rounds
   - 1 Behavioral round

## Coding Interview Focus

### Problem Categories
1. **Arrays & Strings** (20%)
   - Two pointer techniques
   - Sliding window
   - Prefix sums

2. **Trees & Graphs** (25%)
   - Tree traversals
   - Graph algorithms
   - BFS/DFS variations

3. **Dynamic Programming** (20%)
   - Optimization problems
   - State transitions
   - Space optimization

4. **Linked Lists** (15%)
   - Pointer manipulation
   - Cycle detection
   - Merge operations

5. **Stacks & Queues** (10%)
   - Monotonic stacks
   - Priority queues
   - Deque problems

6. **Hash Tables** (10%)
   - Frequency counting
   - Grouping problems
   - Cache design

## Interview Tips for Meta

### Technical Approach
1. **Clarify Requirements**: Ask about edge cases
2. **Discuss Approach**: Explain before coding
3. **Code Cleanly**: Use meaningful variable names
4. **Test Thoroughly**: Walk through examples
5. **Optimize**: Discuss time/space trade-offs

### Communication
- Explain your thought process
- Ask clarifying questions
- Discuss trade-offs
- Be open to hints
- Acknowledge mistakes

### Time Management
- 5 min: Understand problem
- 10 min: Plan approach
- 20 min: Code solution
- 10 min: Test and optimize

## System Design Topics (for senior roles)

1. **Caching Systems**
   - LRU Cache design
   - Cache invalidation strategies

2. **Real-time Systems**
   - Message queues
   - Event streaming

3. **Social Features**
   - Feed generation
   - Recommendation systems

4. **Scalability**
   - Database sharding
   - Load balancing

## Behavioral Questions

### Common Questions
1. "Tell me about a time you faced a difficult problem"
2. "How do you handle disagreements with teammates?"
3. "Describe your most impactful project"
4. "How do you stay updated with technology?"

### STAR Method
- **Situation**: Context
- **Task**: Your responsibility
- **Action**: What you did
- **Result**: Outcome and learning

## Preparation Strategy

### Week 1-2: Fundamentals
- Review data structures
- Practice basic problems
- Master two-pointer and sliding window

### Week 3-4: Medium Problems
- Solve 20-30 medium problems
- Focus on Meta-specific problems
- Practice explaining solutions

### Week 5-6: Hard Problems
- Solve 10-15 hard problems
- Practice under time pressure
- Mock interviews

### Week 7: Final Review
- Review weak areas
- Practice system design
- Behavioral preparation

## Common Mistakes to Avoid
1. Not clarifying requirements
2. Jumping to code without planning
3. Ignoring edge cases
4. Not testing thoroughly
5. Poor variable naming
6. Inefficient solutions
7. Not discussing trade-offs
8. Panicking on hard problems
