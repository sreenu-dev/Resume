# Microsoft Interview Guide

## Company Overview
- **Focus**: Cloud computing, enterprise software, AI/ML, scalability
- **Interview Style**: Algorithm-heavy, system design, practical
- **Difficulty**: Hard
- **Time Limit**: 45 minutes per problem

## Interview Process
1. **Phone Screen** (1 round): 1 medium-hard problem
2. **On-Site** (4-5 rounds):
   - 2-3 Coding rounds
   - 1-2 System Design rounds
   - 1 Behavioral round

## Core Values
1. **Innovation**: Drive technological advancement
2. **Integrity**: Ethical and honest approach
3. **Accountability**: Take responsibility
4. **Respect**: Value diverse perspectives
5. **Collaboration**: Work together effectively

## Coding Interview Focus

### Problem Categories
1. **Arrays & Strings** (15%)
   - Complex string manipulation
   - Advanced array techniques
   - Pattern matching

2. **Trees & Graphs** (25%)
   - Graph algorithms
   - Advanced tree problems
   - Path finding and optimization

3. **Dynamic Programming** (25%)
   - Complex DP problems
   - State compression
   - Optimization techniques

4. **Linked Lists** (10%)
   - Pointer manipulation
   - Complex list operations

5. **Stacks & Queues** (10%)
   - Stack-based problems
   - Queue operations
   - Monotonic structures

6. **Hash Tables** (10%)
   - Frequency counting
   - Grouping and caching

7. **Bit Manipulation** (5%)
   - Bit operations
   - Number theory

## Interview Tips for Microsoft

### Technical Excellence
1. **Optimal Solutions**: Aim for best complexity
2. **Edge Cases**: Handle all scenarios
3. **Code Quality**: Clean, maintainable code
4. **Optimization**: Discuss multiple approaches
5. **Trade-offs**: Explain space-time trade-offs

### Problem-Solving Approach
1. Clarify requirements thoroughly
2. Discuss multiple approaches
3. Analyze complexity
4. Code carefully
5. Test comprehensively
6. Optimize if time permits

### Communication
- Think out loud
- Explain your reasoning
- Ask clarifying questions
- Accept feedback gracefully
- Discuss trade-offs
