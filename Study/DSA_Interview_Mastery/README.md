## 📖 Data Structures Guide

### 1. Arrays and Strings
- **Key Concepts**: Two pointers, sliding window, prefix sum
- **Time Complexity**: O(1) access, O(n) operations
- **Must-Know Problems**: Two Sum, Container With Most Water, Trapping Rain Water
- **Study Time**: 3-4 hours

### 2. Linked Lists
- **Key Concepts**: Fast and slow pointers, reversal, merging
- **Time Complexity**: O(n) access, O(1) insertion/deletion at known position
- **Must-Know Problems**: Reverse Linked List, Detect Cycle, Merge Lists
- **Study Time**: 3-4 hours

### 3. Stacks and Queues
- **Key Concepts**: LIFO/FIFO, monotonic stack, priority queue
- **Time Complexity**: O(1) push/pop, O(log n) for heaps
- **Must-Know Problems**: Valid Parentheses, Daily Temperatures, Sliding Window Maximum
- **Study Time**: 3-4 hours

### 4. Trees and Graphs
- **Key Concepts**: DFS, BFS, topological sort, shortest path
- **Time Complexity**: O(V + E) for traversals
- **Must-Know Problems**: Number of Islands, LCA, Word Ladder, Course Schedule
- **Study Time**: 6-8 hours

### 5. Hash Tables and Sets
- **Key Concepts**: Hash functions, collision handling, frequency counting
- **Time Complexity**: O(1) average, O(n) worst case
- **Must-Know Problems**: Two Sum, Group Anagrams, LRU Cache
- **Study Time**: 3-4 hours

### 6. Heaps and Priority Queues
- **Key Concepts**: Heap property, heapify, priority ordering
- **Time Complexity**: O(log n) insert/delete, O(1) peek
- **Must-Know Problems**: Kth Largest, Top K Frequent, Merge K Lists
- **Study Time**: 3-4 hours

## 🔧 Algorithms Guide

### 1. Sorting Algorithms
- **Coverage**: Bubble, Selection, Insertion, Merge, Quick, Heap, Counting, Radix
- **Key Focus**: Time/space complexity, stability, in-place operations
- **Study Time**: 4-5 hours

### 2. Searching Algorithms
- **Coverage**: Linear, Binary, Ternary, Exponential, Interpolation
- **Key Focus**: Binary search variations, binary search on answer
- **Study Time**: 3-4 hours

### 3. Dynamic Programming
- **Coverage**: 1D, 2D, interval, tree, digit, bitmask DP
- **Key Focus**: State definition, transitions, optimization
- **Study Time**: 8-10 hours

### 4. Greedy Algorithms
- **Coverage**: Activity selection, Huffman coding, MST, Dijkstra's
- **Key Focus**: Greedy choice property, proof techniques
- **Study Time**: 4-5 hours

### 5. Backtracking and Recursion
- **Coverage**: Permutations, combinations, N-Queens, Sudoku
- **Key Focus**: Pruning, constraint satisfaction
- **Study Time**: 5-6 hours
